## Publishing Rule

Before making a public release or submitting to an app store:

1. Replace every unverified audio file with self-created, properly licensed, or public-domain material.
2. Record source URL, author, license, download date and any modification notes.
3. Keep generated assets in a separate table with tool name and editing notes.
4. Do not claim third-party or uncertain assets are MIT licensed.
